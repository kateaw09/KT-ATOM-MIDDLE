คีย์ลัดการทำงาน (Keyboard Shortcuts)

            
ใช้งานได้ทั้งในหน้าเขียนโค้ด Arduino C++ และพื้นที่ทำงานหลัก

          

        

        
      

      

        

          
            
Ctrl + Sบันทึกไฟล์ทั้งหมดลงเครื่องทันที

            
Ctrl + BVerify & Compile เฟิร์มแวร์

            
Ctrl + Shift + Gเปิด Version Control (บันทึกเวอร์ชัน / ย้อนกลับ)

            
Ctrl + Spaceเปิดเมนูช่วยเขียน Autocomplete ทันที

            
Tab / Rightเติมคำเดาอัตโนมัติ (Word Prediction) / ย่อหน้า 4 ช่องว่าง

            
Ctrl + Z / Ctrl + YUndo / Redo (รองรับทั้งโหมด C++ และโหมดบล็อก)

            
Shift + Alt + FFormat Code จัดย่อหน้าและเว้นวรรค C++ อัตโนมัติ

            
Ctrl + /สลับ Line Comment (//) บรรทัดที่เลือก

            
Shift + Alt + Aสลับ Block Comment (/* ... */)

            
Ctrl + F / Ctrl + Hค้นหาและแทนที่ข้อความในไฟล์

            
Alt + Up / Downเลื่อนบรรทัดที่เลือกขึ้น / ลง

            
Ctrl + Dคัดลอกบรรทัดปัจจุบันลงมาด้านล่าง (Duplicate Line)

            
Ctrl + Shift + Kลบบรรทัดปัจจุบันทั้งบรรทัด
